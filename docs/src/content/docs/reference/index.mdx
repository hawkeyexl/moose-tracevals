## Reading these pages

- **Defaults are the resolved values.** Every knob flows through the config file, which fills in
  every default before anything reads it. A CLI flag **overrides** the resolved config instead of
  bypassing it, so the default shown for a flag is the config default it would replace.
- **Unknown configuration keys are errors.** The config schema rejects additional properties at
  every level, so a typo fails loudly instead of being ignored.
- **Deterministic grader options are validated before grading.** A malformed criterion produces an
  `error` outcome naming the offending option, never a silent pass.
